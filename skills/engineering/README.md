# Engineering skills

- **[migration-safety](./migration-safety/SKILL.md)** - Review and execute schema, data, and production migrations with rollback, compatibility, and validation discipline.
- **[ship-check](./ship-check/SKILL.md)** - Final readiness check before claiming work is done, released, merged, or safe to ship.
- **[smallest-safe-change](./smallest-safe-change/SKILL.md)** - Keep implementation work surgical: inspect the real path, minimize blast radius, and avoid unrelated churn.
