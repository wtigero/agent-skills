# Engineering skills

- **[hold-your-horses](./hold-your-horses/SKILL.md)** - Clarify uncertain flow, scope, and contracts before implementation.
- **[prove-it](./prove-it/SKILL.md)** - Do not claim work is done, fixed, tested, or safe without proof.
- **[council](./council/SKILL.md)** - Get an independent, read-only review from Codex, Claude Code, or both.
- **[bug-hunter](./bug-hunter/SKILL.md)** - Trace failures and test competing causes before choosing a fix.
- **[create-verifier](./create-verifier/SKILL.md)** - Build and exercise a project verification guide for a fresh session.
